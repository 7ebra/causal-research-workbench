# Contributing

Keep changes focused and reproducible. Include a behavioral check for changed
timing, data integrity, retry, privacy or persistence logic. Run the offline test
commands in the README and the release check before publishing.

Do not add live credentials, original transcripts, licensed market datasets or
claims of trading performance without independently inspectable evidence.
Preserve existing trial contracts; a new model hypothesis needs a separate
protocol rather than changing a scored experiment.

Document AI assistance and distinguish software correctness from statistical
evidence. Financial example changes must state their price basis, target timing,
cost assumptions and limits. Use synthetic examples for pull requests.
