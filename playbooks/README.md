# Reusable research playbooks

These original skill packages encode procedures, not statistical certification.
They can be read as standalone operating guides or installed as local Codex skills.

- [Research validation](research-validation/SKILL.md): chronology, controls, costs,
  sample adequacy and rejection.
- [Source provenance](source-provenance/SKILL.md): publication/observation clocks,
  as-of versions and revisions.
- [Controlled model updates](controlled-model-updates/SKILL.md): bounded challengers,
  immutable trials and independent future confirmation.

Each package contains its instructions, UI metadata and a focused record template.
They grant no additional permission to trade, deploy, publish data or buy resources.
